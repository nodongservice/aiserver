# 03. AI and LLM Policy

## AI 사용 원칙

AI는 결정권자가 아니라 설명 보조자이다.

AI는 점수를 직접 결정하지 않는다.

점수 계산은 규칙 기반 코드에서 수행하고, LLM은 계산된 결과를 쉬운 한국어로 설명한다.

## LLM 사용 범위

LLM을 사용할 수 있는 영역은 다음과 같다.

- 사용자 입력을 접근성 태그로 구조화
- 추천 사유 설명 생성
- 위험요소 요약
- 상담기관용 요약 생성
- 어려운 용어를 쉬운 문장으로 설명
- JSON 형태의 보조 분류 생성

LLM을 사용하면 안 되는 영역은 다음과 같다.

- 최종 점수 임의 생성
- 장애 정도 판정
- 취업 가능 여부 단정
- 의료적 조언
- 법률적 판단
- 특정 기업의 차별 여부 단정
- 사용자가 입력하지 않은 장애 상태 추정
- 민감정보 추론

## 모델 후보

1순위는 Qwen2.5 7B Instruct이다.

이유는 다음과 같다.

- 한국어 포함 다국어 지원
- JSON 구조화에 무난
- 요약과 설명 생성에 적합
- MVP에서 테스트하기 좋음

2순위는 Llama 3.1 8B Instruct이다.

장점은 다음과 같다.

- 범용성 좋음
- 생태계가 넓음

주의점은 다음과 같다.

- 한국어 품질은 Qwen 대비 검증 필요

3순위는 Mistral 7B Instruct이다.

장점은 다음과 같다.

- 가볍고 빠름

주의점은 다음과 같다.

- 한국어 품질은 별도 테스트 필요

한국어 특화 후보는 다음과 같다.

- EXAONE 계열
- EEVE Korean 계열

## 프롬프트 원칙

프롬프트는 app/prompts에 둔다.

프롬프트는 다음 원칙을 따른다.

- 응답은 JSON으로 제한한다.
- 필수 필드를 명시한다.
- 모르는 내용은 unknown으로 표시하게 한다.
- 사용자 장애 상태를 임의로 추정하지 않게 한다.
- 데이터에 없는 편의시설을 있다고 말하지 않게 한다.
- 추천 사유와 주의사항을 분리한다.
- 쉬운 한국어를 사용하게 한다.
- 단정적 표현을 금지한다.
- 의료, 법률, 차별 판단을 금지한다.

## LLM 응답 검증

LLM 응답은 반드시 검증 후 사용한다.

검증 기준은 다음과 같다.

- JSON 파싱 가능 여부
- 필수 필드 존재 여부
- enum 값 유효성
- 금지 표현 포함 여부
- 점수 임의 생성 여부
- unknown 처리 여부

검증 실패 시 다음 중 하나를 수행한다.

- 1회 재시도
- 규칙 기반 fallback 사용
- LLM 설명 없이 점수와 기본 설명만 반환

## Fallback 정책

LLM 호출이 실패해도 전체 분석이 실패하면 안 된다.

fallback 예시는 다음과 같다.

- LLM 설명 생성 실패: 규칙 기반 설명 반환
- LLM 태그화 실패: 체크박스 기반 태그만 사용
- JSON 파싱 실패: 재시도 후 실패 시 기본 schema 반환
- LLM timeout: 점수 계산 결과만 반환

## 표현 원칙

좋은 표현 예시는 다음과 같다.

- 이 공고는 사용자가 선택한 조건과 일부 잘 맞습니다.
- 확인 가능한 데이터 기준으로는 엘리베이터 정보가 있습니다.
- 출입구 접근성은 추가 확인이 필요합니다.
- 전화 응대가 포함될 수 있어 청각장애 사용자는 지원 전 확인이 필요합니다.
- 현재 데이터만으로는 건물 내부 접근성을 확정하기 어렵습니다.

피해야 할 표현은 다음과 같다.

- 이 직장은 완벽히 접근 가능합니다.
- 이 사용자는 이 일을 할 수 없습니다.
- 장애인에게 부적합합니다.
- 무조건 추천합니다.
- 위험하지 않습니다.
- 확실히 지원 가능합니다.

## 민감정보 처리

LLM에 전달하는 정보는 최소화한다.

LLM에 전달하지 않는 것이 원칙인 정보는 다음과 같다.

- 전화번호
- 이름
- 상세 주소
- 원문 장애 설명
- 주민등록번호
- 인증 정보
- API 키
- OAuth 토큰

장애 유형은 사용자가 명시적으로 선택한 경우에만 태그로 전달한다.

예시는 다음과 같다.

- wheelchair_user
- low_vision
- blind
- deaf_or_hard_of_hearing

원문 문장보다 정규화된 태그를 우선 전달한다.
