# 01. Project Context

## 프로젝트 목적

BridgeWork는 장애인 구직자와 이동약자가 현실적으로 출근 가능한 일자리를 찾을 수 있도록 돕는 서비스이다.

FastAPI AI/GIS Service는 공공데이터, 사용자 조건, 공고 정보를 바탕으로 접근성 점수와 추천 설명을 생성한다.

## 핵심 사용자

1차 핵심 사용자는 다음과 같다.

- 구직 중인 장애인
- 중증장애인
- 이동약자
- 지역 기반 취업 희망자
- 휠체어 사용자
- 저시력 또는 전맹 사용자
- 청각장애 사용자

확장 사용자는 다음과 같다.

- 직장 접근성을 중요하게 보는 구직 청년
- 고용복지플러스센터
- 장애인고용공단 지사
- 지자체 취업지원기관
- 장애인 채용을 희망하는 기업

## 서비스 방향

이 서비스는 단순히 공고를 많이 보여주는 것이 아니라, 사용자가 실제로 출근 가능하고 업무환경을 확인할 수 있는 공고를 설명 가능하게 추천하는 것을 목표로 한다.

중요한 가치는 다음과 같다.

- 설명 가능한 추천
- 접근성 근거 제공
- 장애 유형별 조건 반영
- 민감정보 선택 입력
- 과도한 개인정보 요구 지양
- 데이터 부족 시 추가 확인 필요로 표시
- 공공데이터 기반 근거 우선

## 주요 기능

FastAPI AI/GIS Service의 주요 기능은 다음과 같다.

- 사용자 입력을 접근성 조건으로 구조화
- 장애 유형별 태그 정규화
- 사업장 주변 접근성 피처 계산
- 사용자별 접근성 점수 계산
- 공고별 통근 접근성 분석
- 추천 사유 생성
- 위험요소 설명 생성
- 상담기관용 요약 생성
- LLM 기반 쉬운 설명 생성

## MVP 우선순위

MVP에서는 다음 기능을 우선 구현한다.

1. 사용자 조건 태그 정규화
2. 공공데이터 기반 접근성 피처 계산
3. 접근성 점수 계산
4. 추천 사유 및 위험요소 설명
5. Spring Backend 연동

다음 기능은 추가 개발로 둔다.

- 실제 장애 유형별 길찾기
- OCR 기반 포트폴리오 생성
- 직업훈련 과정 추천
- 상담기관용 고급 리포트
- 실시간 환승 최적화
- 경사도 기반 보행 경로 분석

## 도메인 표현 원칙

권장 표현은 다음과 같다.

- 장애인 구직자
- 휠체어 사용자
- 저시력 사용자
- 전맹 사용자
- 청각장애 사용자
- 이동약자
- 교통약자
- 접근성 지원
- 편의 제공
- 추가 확인 필요

지양 표현은 다음과 같다.

- 정상인
- 불구
- 장애 때문에 불가능
- 부적합 단정
- 무조건 가능
- 완벽히 안전
